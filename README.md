# whatsapp-ai-agent
# 🤖 WhatsApp AI Agent - Atendimento Automatizado com Inteligência Artificial

Este repositório contém um sistema de automação comercial de ponta que conecta o WhatsApp à API da OpenAI (ChatGPT) para criar atendentes virtuais humanos, inteligentes e focados em vendas para negócios locais e clínicas.

## 💼 O Problema que este Código Resolve
Empresas perdem até 40% dos clientes em potencial por demorarem mais de 10 minutos para responder no WhatsApp. Este agente virtual atende **instantaneamente, 24 horas por dia, 7 dias por semana**, qualificando o cliente e preparando o agendamento.

## 🚀 Funcionalidades Técnicas
- **Conexão Nativa:** Integração estável com o WhatsApp via WebSockets.
- **Inteligência Contextual:** IA configurada com a persona, regras de negócio e tom de voz específicos da empresa.
- **Sessão Persistente:** Autenticação segura que não exige re-escanear o QR Code caso o sistema reinicie.
- **Foco em Conversão:** Scripts desenhados para retenção de clientes e chamadas para ação (agendamentos).

## 🛠️ Tecnologias Utilizadas
- **Node.js** (Ambiente de execução)
- **JavaScript ES6+**
- **Baileys API** (Conexão WhatsApp)
- **OpenAI API (GPT-3.5/GPT-4)** (Cérebro do Agente)
